# Dataset placeholder

The full CID datasets are intentionally not copied into this repository during active experimentation.

At the final evaluation freeze, this directory will record:

- immutable dataset release/tag
- Hugging Face repository/revision
- DOI where applicable
- file checksums
- train/validation/test split manifests
- materialization/version identifiers used by each experiment

Current public dataset lineage includes CID-Dataset; the exact final revision will be pinned at release time.
